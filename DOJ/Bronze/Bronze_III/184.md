# 문제

쿠옹이는 경희대학교 중앙도서관 열람실을 예약했다. 예약한 시간에 열람실을 사용하려 했으나 예약이 되어있지 않은 것을 발견했다. 쿠옹이가 다시 예약 기록을 확인해보니 오후 6시로
예약을 해야 했지만 실수로 오전 6시로 잘못 예약을 해버린 것이었다. 쿠옹이는 다시 이런 실수를 하지 않기 위해 12시간제와 24시간제를 헷갈리지 않았는지 알려주는 프로그램을
만들기로 했다. 도서관 열람실 예약정보는 시작시각과 끝시각으로 이루어져 있다. 모든 예약한 시각이 12시간제에 존재하는 시간인지를 확인하고 시간을 다시 확인할지 알려줄 지 여부를
출력하라.

12시간제와 24시간제에 모두 존재하는 시각은 01:00−12:59이고 24시간제에만 존재하는 시각은 00:00−00:59와 13:00−23:59이다.

## 입력

첫째 줄에 쿠옹이가 열람실을 예약한 횟수 N이 주어진다. (1 ≤ N ≤ 10^5)
둘째 줄부터 N줄에 걸쳐 예약 정보가 `"hh:mm - hh:mm"`의 형태로 주어진다. (00 ≤ hh ≤ 23; 00 ≤ mm ≤ 59)

## 출력

모든 예약의 시작시각과 끝시각이 12시간제와 24시간제에 모두 존재한다면 실수를 했을 여지가 있으니 `"check the time again"`을 출력한다. 그렇지 않다면 `"KHU
Library"`를 출력한다.

# 풀이

# 문자열 슬라이싱을 이용한 방법

```python
def checkTF(s, t, e):
    return s <= t <= e

n = int(input())
c = 0

for _ in range(n):
    r = input()
    s = int(r[0:2])
    e = int(r[8:10])
    if checkTF(1, s, 12) and checkTF(1, e, 12):
        c += 1

print("check the time again" if c == n else "KHU Library")
```

c 변수는 실수를 했을 여지가 있는 시간을 발견한 횟수다. 만약 c가 n이랑 같다면 모든 예약 시간이 실수를 했을 여지가 있는지 판단할 수 있다.

checkTF 함수는 시작, 현재, 끝을 입력받아 현재는 시작 또는 끝 또는 시작과 끝 사이라면의 조건을 반환하므로 조건이 성립할 시 True를 반환한다. 문자열 슬라이싱을 통해
s엔 r의 첫 번째 hh를, e엔 r의 두 번째 hh를 int로 형변환해 할당한다.

if문 조건은 12시간제와 24시간제 모두 포함될 수 있는 시각이다. 만약 모두 참이라면 if문의 결과는 참이 되므로 실수를 했을 여지가 있으니 c를 1 증가시켜준다.

삼항 연산자로 c가 n이랑 같을 때는 실수를 했을 여지가 있으니 "check the time again"을, 그게 아니라면 24시간제인 것을 확신할 수 있으니 "KHU
Library"를 출력한다.

# `replace()`를 이용한 풀이다.

```python
n = int(input())
c = 0

for _ in range(n):
    h1, m1, h2, m2 = map(int, input().replace(":", " ").replace("-", "").replace(":", " ").split())
    if 0 < h1 < 13 and 0 < h2 < 13:
        c += 1

print("check the time again" if c == n else "KHU Library")
```

c 변수는 실수를 했을 여지가 있는 시간을 발견한 횟수다. 만약 c가 n이랑 같다면 모든 예약 시간이 실수를 했을 여지가 있는지 판단할 수 있다.

시간을 입력받을 때는 `hh:mm - hh:mm`이므로 콜론이 2개, 하이픈이 1개 있다. replace ()를 사용해서 모두 공백으로 바꿔준 뒤, 공백을 기준으로 나눠 int로
형변환한 뒤 각각 h1, m1, h2, m2 변수에 할당한다.

if문 조건은 12시간제와 24시간제 모두 포함될 수 있는 시각이다. 여기서 분은 중요하지 않으므로 m1과 m2는 사용하지 않는다. 만약 저기에 h1과 h2가 포함된다면 실수를
했을 여지가 있으니 c를 1 증가시켜준다.

삼항 연산자로 c가 n이랑 같을 때는 실수를 했을 여지가 있으니 "check the time again"을, 그게 아니라면 24시간제인 것을 확신할 수 있으니 "KHU
Library"를 출력한다.
