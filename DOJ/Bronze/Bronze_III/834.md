# 문제

0과 1로만 이루어진 길이 N의 문자열 S가 주어진다.

문자열 S에서 `01`이 등장할 때마다 이를 하나의 `@`로 바꾸고 나머지 문자는 그대로 두어 변환할 문자열을 출력하자.

## 입력

첫 번째 줄에 양의 정수 N이 주어진다 (1 <= N <= 100)

두 번째 줄에 문자열 S가 주어진다.

## 출력

첫 번째 줄에 문자열 S에 등장하는 모든 `01`을 `@`로 바꾼 문자열을 출력한다.

# 풀이

```python
n = int(input())
s = input()

t = []

for i in range(n):
    t.append(s[i])

for i in range(n - 1):
    if (t[i] == "0" and t[i + 1] == "1"):
        t[i] = "@"
        t[i + 1] = ""

print("".join(t))
```

반복문을 돌면서 문자열의 길이를 바꾸게 된다면 인덱싱에 오류가 생길 수 있기 때문에 문자열 s를 t라는 리스트에 하나씩 추가해준다.

`len(t)` 는 n과 같으므로 n - 1번 반복을 시작한다. 왜 -1을 하냐면 0과 1은 한 쌍이기 때문에 마지막 인덱스에 0이 등장한다고 해도 조건을 대입해볼 필요가 없을
뿐더러 인덱스 범위 초과 오류가 뜨기 때문이다. 만약 t[i]가 "0"이고 t[i + 1]이 "1"일 때 `01`이 등장한다는 뜻이므로 t[i]는 "@"로, t[i + 1]은 "
"로 바꿔준다. 여기서는 왜 이게 가능하냐면 t[i + 1]은 ""라는 요소를 가지고 있는 것이기 때문에 길이에 전혀 영향을 끼치지 않는다.

모든 반복을 마쳤다면 "".join (t)를 print해준다.
