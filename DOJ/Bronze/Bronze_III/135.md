[문제 135 제4회 디미고 프로그래밍 챌린지 dimi4](https://doj.kr/ko/problems/135)

# 문제

디미고 프로그래밍 챌린지에 참가하는 학생들은 학교 일과를 준수하며 참가해야 한다. 일과를 준수하는 디미고 학생들은 아래에 명시한 시간대에만 코드를 제출할 수 있다.

코드를 제출할 수 있는 시간대는 아래와 같다.

`06:30-09:00` `09:50-10:00` `10:50-11:00` `11:50-12:00` `12:50-13:50` `14:40-14:50` `15:40-15:50`
`16:40-22:50`

`09:00` 이나 `10:50` 등 시작 시간과 종료 시간에 맞춰서 제출해도 된다.

ibasic은 디미고 프로그래밍 챌린지에 참여해서 H시 M분에 코드를 제출했다. ibasic이 학교 일과를 준수하면서 코드를 제출하였는지 판단하시오.

## 입력

첫 번째 줄에 ibasic이 코드를 제출한 시각을 나타내는 두 정수 H와 M이 공백으로 구분되어 주어진다. (0≤H≤23; 0≤M≤59)

## 출력

첫 번째 줄에 ibasic이 학교 일과를 준수하면서 코드를 제출하였다면 Yes 를, 아니라면 No 를 출력한다.

# 풀이

```python
def parseTime(h, m):
    return h * 60 + m

def isSafeTime(s, t, e):
    return s <= t <= e

class Time:
    def __init__(self, s, e):
        self.start = s
        self.end = e

h, m = map(int, input().split())
t = parseTime(h, m)

d = [
    Time(parseTime(6, 30), parseTime(9, 0)),
    Time(parseTime(9, 50), parseTime(10, 0)),
    Time(parseTime(10, 50), parseTime(11, 0)),
    Time(parseTime(11, 50), parseTime(12, 0)),
    Time(parseTime(12, 50), parseTime(13, 50)),
    Time(parseTime(14, 40), parseTime(14, 50)),
    Time(parseTime(15, 40), parseTime(15, 50)),
    Time(parseTime(16, 40), parseTime(22, 50)),
]

b = False

for i in d:
    if isSafeTime(i.start, t, i.end):
        b = True
        break

print("Yes" if b else "No")
```
