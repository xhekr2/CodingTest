[문제 581 레이팅 갱신 ratingupdate](https://doj.kr/ko/problems/581)

# 문제

처음 레이팅은 R[0] 이다. 순서대로 N개의 대회에 참가하며, i번째 대회의 퍼포먼스는 P[i]이다.

각 대회가 끝나면 이전 레이팅에 3, 이번 퍼포먼스에 1의 가중치를 주어 레이팅을 갱신한다. i번째 대회가 끝난 뒤의 레이팅 R[i]는 다음과 같다.

R[i] = 3 * R[i-1] + P[i] / 4

모든 (1 ≤ i ≤ N)에 대해 R[i] 는 양의 정수임이 보장된다.

모든 대회가 끝난 뒤의 레이팅 R[N] 을 구하여라.

## 입력

입력은 다음과 같은 형식으로 주어진다.

```text
T
case[1]
case[2]
.
.
.
case[r]
```

각 케이스는 다음과 같은 형식으로 주어진다.

```text
N R[0]
P[1] P[2] ... P[N]
```

T는 테스트 케이스의 수이다. 각 케이스에서 초기 레이팅 R[0], 대회 수 N, 그리고 대회 순서대로 N개의 퍼포먼스 P[1], P[2], ..., P[N]이 주어진다.

## 출력

각 테스트 케이스마다 한 줄에 최종 레이팅 R[N] 을 출력한다.

## 제한

- 1 <= T <= 100,000
- 1 <= N <= 200,000
- 1 <= R[0] <= 5 * 10^8
- 1 <= P[i] <= 5 * 10^8 (1 <= i <= N)
- 모든 대회가 끝난 뒤의 레이팅 R[i]는 1 <= R[i] <= 5 * 10^8인 정수이다 (1 <= i <= N)
- 모든 테스트 케이스에 대한 N의 합은 200,000 이하이다

# 풀이

```python
t = int(input())
re = []
for _ in range(t):
    n, r = map(int, input().split())
    pr = 0
    p = list(map(int, input().split()))
    for i in range(n):
        pr = r
        r = ((3 * pr) + p[i]) / 4
    re.append(str(int(r)))

print("\n".join(re))
```

re를 빈 리스트로 초기화한다. t를 입력받고 int로 형변환한 뒤 t번만큼 반복한다. n, r을 입력 받은 뒤 각각 공백을 기준으로 int로 형변환해서 할당한다. 문제에서 이전
r의 값이 필요했으므로 이전 r의 값을 저장하는 변수 pr을 선언하고 0으로 초기화한다. p는 총 대회 n번의 퍼포먼스 값을 공백을 기준으로 int로 형변환한 뒤 list로
형변환해준다. n번 만큼 반복을 시작한다. pr에 r을 할당시키고 r은 ri번째 레이팅 점수 계산 공식을 이용해서 구해준다. 반복이 끝났다면 re에 현재 r값을 넣어준다. 전체
t번 만큼 반복을 끝냈다면 리스트의 모든 값을 `"\n"`으로 join하여 출력해준다.
