[문제 22 박수 clap](https://doj.kr/ko/problems/22)

# 문제
재원이는 박수를 일정한 간격으로 치는 연습을 하고 있다. 재원이가 박수를 친 시각이 순서대로 T1, T2,...,TN초 라고 하자.
모든 1 <= i <= N에 대해 Ti+1 - Ti가 같다면 재원이가 일정한 간격으로 박수를 쳤다고 한다. N = 1인 경우에는 항상 일정한 간격으로 박수를 친 것으로 본다.
재원이가 일정한 간격으로 박수를 쳤는지 판별하라.
# 풀이
```python
n = int(input())
t = list(map(int, input().split()))

if (n == 1):
    print("Yes")

else:
    b = True
    r = t[1] - t[0]
    for i in range(0, len(t) - 1):
        if (r == t[i + 1] - t[i]):
            continue
        else:
            b = not b
            break

    print("Yes" if b else "No")
```
