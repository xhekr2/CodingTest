[문제 22 박수 clap](https://doj.kr/ko/problems/22)

# 문제

재원이는 박수를 일정한 간격으로 치는 연습을 하고 있다. 재원이가 박수를 친 시각이 순서대로 T[1], T[2], ..., T[N]초 라고 하자. 모든 1 <= i <= N에 대해
T[i + 1] - T[i]가 같다면 재원이가 일정한 간격으로 박수를 쳤다고 한다. N = 1인 경우에는 항상 일정한 간격으로 박수를 친 것으로 본다. 재원이가 일정한 간격으로
박수를 쳤는지 판별하라.

## 입력

입력은 다음과 같은 형식으로 주어진다.

```text
N
T[1] T[2] ... T[N]
```

## 출력

첫째 줄에 재원이가 일정한 간격으로 박수를 쳤다면 `Yes`, 그렇지 않으면 `No`를 출력한다.

## 제한

- 1 <= N <= 100
- 0 <= T[i] <= 1,000,000,000 (1 <= i <= N)
- T[1] < T[2] < ... < T[N]

# 풀이

```python
n = int(input())
t = list(map(int, input().split()))

if (n == 1):
    print("Yes")

else:
    b = True
    r = t[1] - t[0]
    for i in range(len(t) - 1):
        if (r == t[i + 1] - t[i]):
            continue
        else:
            b = not b
            break

    print("Yes" if b else "No")
```

n을 입력 받은 뒤 int로 형변환을 하고, t를 입력받은 뒤 공백을 기준으로 int로 형변환한 뒤에 나온 map 객체를 list로 형변환한다. n이 1일 땐 항상 일정한 간격으로
박수를 친 것으로 보므로 if문을 사용해 확인한 뒤 아니라면 플래그 용도로 사용할 불리언 변수 b를 선언한 뒤 False로 초기화한다. r은 간격을 구하기 위해 선언해주었다.

제한 사항에 n의 값은 1 이상인데, 1이라면 if문이 참이므로 여기서 t의 요소 개수는 2이상임이 보장된다. 모든 간격이 동일하다는 조건 아래에 r은 어디에 대입해도 괜찮다.
t의 길이 -1번 반복을 시작하며 만약 r과 t[i + 1] - t[i]가 같을 때는 반복을 넘어가고 그렇지 않다면 b의 값을 부정해준다. 선언했을 때 False를 할당했으므로
True가 되고 break로 반복을 종료한다.

삼항 연산자를 사용하여 print해준다.
