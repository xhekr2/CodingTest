# 문제

당신은 트리비와 박수를 치려 한다. 당신이 박수를 한 번 칠 때마다 트리비도 당신을 따라서 박수를 한 번 친다. 하지만, 트리비는 박수를 너무 많이 치면 지치기 때문에 트리비가
박수를 총 K번 쳤다면 그 후는 박수를 치지 않고 휴식한다.

당신은 박수를 N번 치려고 한다. 당신과 트리비 합쳐서 총 박수를 몇 번 쳤을까?

# 풀이

```python
n, k = map(int, input().split())
t = n if n < k else n - (n - k)
print(n + t)
```
