[문제 606 시노카의 그래픽스 공부 sinokagraphics](https://doj.kr/ko/problems/606)

# 문제

시노카는 정다각형으로 만든 모델을 삼각형으로 나누어 렌더링하려 한다. 각 정다각형을 겹치지 않는 삼각형으로 나눌 때 필요한 삼각형의 개수를 구하라

## 입력

입력은 다음과 같은 형식으로 주어진다.

```text
T
case[1]
case[2]
.
.
.
case[T]
```

각 케이스는 다음과 같은 형식으로 주어진다.

```text
N
A1 A2 ... AN
```

## 출력

각 케이스마다 N개의 줄에 각 정다각형을 나누는 삼각형의 개수를 순서대로 출력한다.

## 제한

- 1 <= T <= 100,000
- 1 <= N <= 100,000
- 3 <= A[i] <= 10^9
- 모든 케이스에 대한 N의 합은 200,000 이하이다.

# 풀이

```python
t = int(input())
r = []

for _ in range(t):
    n = int(input())
    a = map(int, input().split())
    for i in a:
        r.append(str(i - 2))

print("\n".join(r))
```
