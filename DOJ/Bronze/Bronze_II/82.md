[문제 82 Array and Counting 1 arraycount](https://doj.kr/ko/problems/82)

# 문제

양의 정수 N과 길이가 2N인 수열 A = [A[1], A[2], ..., A[2N]]이 주어진다. 다음 조건을 만족하는 정수 순서쌍 (i, j)의 개수를 구하여라.

- 1 <= i <= N
- 1 <= j <= N
- A[i] + A[j] = A[i + j]

## 입력

입력은 다음과 같은 형식으로 주어진다.

```text
N
A[1], A[2], ..., A[2N]
```

## 출력

첫째 줄에 정답을 출력한다.

## 제한

- 1 <= N <= 2,000
- 1 <= A[i] <= 1,000,000,000 (1 <= i <= 2N)

# 풀이

```python
n = int(input())
a = list(map(int, input().split()))
c = 0

for i in range(n):
    for j in range(n):
        if a[i] + a[j] == a[i + j + 1]:
            c += 1

print(c)
```

정수 N을 입력받고, A는 공백을 기준으로 int로 형변환 뒤 리스트로 저장한다. c는 정수 순서쌍의 개수를 나타내기 위한 변수다. for문을 이용하여 i와 j를 최대 N번
반복하게 한다. 위 코드에선 만약 i가 0, j가 0일 때 a의 0번과 a의 0번을 더한 값이 a의 1과 같은가 라면 c를 1 증가시켜라 라는 뜻이다. 문제에선 A[i] +
A[j] = A[i + j]인 순서쌍을 찾으라고 했는데 왜 여기선 마지막에 1을 더해주었냐면 리스트의 인덱스는 0번부터 시작하기 때문이다. 문제에서 주어진 수열 A는 원소가
1번부터 시작한다.

반복을 다 했다면 조건을 모두 확인한 것이기에 순서쌍 개수인 c를 출력해준다.
