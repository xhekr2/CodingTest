[문제 721 맛있는 사과 delicious-saga](https://doj.kr/ko/problems/721)

# 문제

테라는 과수원에서 갓 수확한 사과가 '맛있는 사과'인지 판별하려고 한다.

과수원의 엄격한 기준에 따르면, 사과의 크기가 A 이상이고 당도가 B 이상일 때만 그 사과를 '맛있는 사과'라고 부른다. 크기나 당도 중 하나라도 기준치에 미치지 못하면 맛있는
사과가 아니다.

테라가 방금 수확한 사과의 크기 S와 당도 W가 주어졌을 때, 이 사과가 맛있는 사과인지 판단하는 프로그램을 작성하라.

## 입력

첫째 줄에 맛있는 사과의 기준이 되는 크기 A와 당도 B가 공백으로 구분되어 주어진다. (0 <= A, B <= 100)
둘째 줄에 테라가 방금 수확한 사과의 크기 S와 당도 W가 공백으로 구분되어 주어진다. (0 <= S, W <= 100)

## 출력
테라가 수확한 사과가 맛있는 사과라면 `YES`를 아니면 `NO`를 출력한다.

# 풀이

```python
a, b = map(int, input().split())
s, w = map(int, input().split())

if (a <= s) and (b <= w):
    print("YES")
else:
    print("NO")
```
