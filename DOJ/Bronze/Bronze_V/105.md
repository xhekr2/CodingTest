[문제 105 파이썬 지원 python support](https://doj.kr/ko/problems/105)

# 문제

파이썬은 매년 10월에 새로운 메이저 버전인 Python 3.X.0을 출시한다.

이 문제에서는 Python 3.12.0이 2023년에 출시되었다고 하며, 이후 Python 3.X.0의 출시 연도는 매년 1씩 증가한다고 정의한다. 즉, Python 3.X.0의
출시 연도는 X + 2011이다.

각 버전은 출시된 해부터 5년 뒤의 해까지 지원된다. 더 정확히는, Python 3.X.0의 지원 종료 연도는 X+2016이며, 이 문제에서는 그 해 전체를 지원 기간에 포함한다고
본다.

예를 들어 Python 3.12.0은 2023년에 출시되었고, 2028년까지 지원되는 것으로 본다.

정수 X와 현재 연도 Y가 주어진다. Python 3.X.0이 현재 연도 Y에 지원 중인지 판별하라.

아직 출시되지 않은 버전은 지원 중인 것으로 보지 않는다.

## 입력

입력은 다음 식으로 주어진다

```text
A B
```

## 출력

Python 3.X.0이 현재 연도 `Y`에 지원 중이라면 `Support`를 출력한다. 그렇지 않다면 `End of Life`를 출력한다.

## 제한

- 12 <= X <= 1,000,000,000
- 2023 <= Y <= 1,000,000,000
- X와 Y는 정수이다.

# 풀이

```python
x, y = map(int, input().split())

if (x + 2016 >= y) and (x + 2011 <= y):
    print("Support")
else:
    print("End of Life")
```
